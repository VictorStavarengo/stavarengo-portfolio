# stavarengo — portfólio

[![CI](https://github.com/VictorStavarengo/stavarengo-portfolio/actions/workflows/ci.yml/badge.svg)](https://github.com/VictorStavarengo/stavarengo-portfolio/actions/workflows/ci.yml)

Site pessoal de João Victor Stavarengo: portfólio, jornada profissional, competências e projetos, feito com React 19, TypeScript e Vite.

**Ao vivo:** [jvstavarengo.vercel.app](https://jvstavarengo.vercel.app)

## O que tem aqui

- Seções editoriais com paleta madeira/preto/branco e tipografia Cabinet Grotesk
- Projetos com **prévia ao vivo em iframe** (Encaixe, Pulso, Catálogo de Jogos, Pokédex, Lista de Tarefas)
- Competências em grupos com chips interativos
- Currículo em PDF para download
- Open Graph completo (prévia no WhatsApp/LinkedIn) e acessibilidade por teclado

## Stack

`React 19` `TypeScript` `Vite` `framer-motion` `ESLint`

## Rodando localmente

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
```

## Deploy

O deploy é contínuo: cada push na `main` publica automaticamente na Vercel (projeto `victorstavarengo`).
